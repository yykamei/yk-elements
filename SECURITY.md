# Security Policy

## Supported versions

Security fixes are provided for the latest published version of
`@yykamei/yk-elements`.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting:

https://github.com/yykamei/yk-elements/security/advisories/new

Do not open a public issue for a suspected vulnerability. Include the affected
version or commit, a minimal reproduction, and the impact you expect. Responses
are best effort.

## Scope

This policy covers the component source, the built `dist/` output, and the
catalog site. Vulnerabilities in third-party dependencies should be reported to
their maintainers.
